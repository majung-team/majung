# 마중 (Majung)

**데리러 가는 사람과 기다리는 사람을 연결하는 차량 내비게이션 연동 픽업 서비스**

“어디쯤이야?” “지금 내려갈까?”

차량에서는 탑승자의 준비 상태를 확인하고, 탑승자는 휴대전화로 차량의 실시간 위치와 도착 예정 시간을 확인합니다.

## 소개

누군가를 데리러 갈 때 “어디야?”, “지금 나갈까?” 같은 연락을 반복하게 됩니다.
**마중**은 차량 내비게이션의 실시간 위치·도착 예정 시간(ETA)과 탑승자의 외출 준비 상태를 실시간으로 주고받는 서비스입니다.
탑승자가 준비를 마치면 차량 화면에서 즉시 확인하고, 차에 타면 픽업을 종료하여 위치 공유가 안전하게 완료됩니다.

## 사용 흐름

| 순서 | 운전자 (차량 화면) | 탑승자 (휴대전화 웹) |
| :---: | :--- | :--- |
| **1. 약속 만들기** | 내비게이션에서 만날 장소를 설정하고 픽업 생성 | 초대 링크 또는 마중 요청 전달받기 |
| **2. 초대 및 연결** | QR/링크 생성 및 탑승자 연결 확인 | 링크 접속 또는 운전자 검색을 통해 참여 |
| **3. 이동 중** | 탑승자의 준비 완료 상태를 차량 화면에서 실시간 확인 | 차량의 실시간 위치 및 남은 시간(ETA) 확인, 준비 상태 변경 |
| **4. 도착 및 탑승** | 도착 알림 후 실제 탑승 확인 및 픽업 완료 | 도착 알림 확인 및 위치 공유 자동 종료 |

운전자가 생성한 QR/초대 링크 방식뿐만 아니라, 탑승자가 운전자를 검색해 픽업을 직접 요청하는 방식도 함께 지원합니다. 탑승자는 장소명·주소 검색, 지도 핀 선택 또는 현재 위치를 기반으로 픽업 장소와 메시지를 전송할 수 있습니다. 운전자는 들어온 요청들을 수락하여 대기열에 두고 순차적으로 픽업을 진행할 수 있습니다.

## 전체 구조

![마중 서비스 구성](docs/diagrams/overview.svg)

차량 앱과 웹 클라이언트는 Spring Boot 서버 API를 통해 유기적으로 연결됩니다.
- **차량 앱**: Pleos Android Automotive(AAOS) 기반 네이티브 앱
- **탑승자 화면**: 별도 앱 설치 없이 링크로 즉시 열리는 모바일 웹
- **서버**: SDK의 차량 위치·ETA 및 픽업 상태를 관리하고, 탑승자의 실시간 준비 상태를 차량에 전달

**[상세 아키텍처 문서](docs/architecture.md)** — 차량 서비스·화면·SDK 연동, 데이터 저장소 및 배포 구성 안내.

## 현재 구현 및 검증 범위

2026-10-26 기준 검증 현황입니다. 공식 Pleos 에뮬레이터 및 클라우드 배포 환경에서 기능 동작 검증을 완료했습니다. [최신 변경과 운영 확인](docs/runtime-2026-10-26.md) 및 [팀 테스트 안내](docs/team-testing.md)를 함께 참고해 주시기 바랍니다.

| 항목 | 구현 및 검증 내용 |
| --- | --- |
| **공개 서버·웹 운영** | `https://majung.cloud` 운영 중. 전용 VM, PostgreSQL, Caddy 리버스 프록시 및 GitHub Actions CI/CD 파이프라인 구축 완료 |
| **초대 기반 픽업** | 링크 접속 시 별도 복잡한 절차 없이 즉시 픽업 세션 참여. 차량 화면에서 탑승자 연결 해제 및 신규 초대 지원 |
| **카카오 로그인·사람 찾기** | HTTPS 환경에서 소셜 로그인, 닉네임 설정 및 사용자 간 연결 요청/수락 흐름 구현 완료 |
| **다중 픽업 대기열** | 운전자가 여러 픽업 요청을 수락하여 순차 대기열에 등록하고 한 건씩 차례로 진행하는 흐름 검증 완료 |
| **경유지 및 경로 연동** | 카카오 지오코더 연동 장소 좌표 매핑 및 내비게이션 목적지 연동 처리 |
| **재실행 및 백그라운드 공유** | 앱 재실행 시 픽업 세션 자동 복구 및 포그라운드 서비스를 통한 화면 종료 시 위치 공유 유지 |
| **주행 안전 UI 제한** | 차량 기어(P/D단) 상태에 따라 정차 시 상세 화면과 주행 시 읽기 전용 요약(ETA, 준비 상태) 모드로 자동 전환 |
| **준비 상태 실시간 전달** | 탑승자의 '외출 준비 완료' 토글 신호가 서버를 거쳐 차량 앱 화면에 지연 없이 반영 |
| **도착 임박 알림** | VAPID 기반 Web Push 알림 연동 (차량 도착 3분 전 탑승자 브라우저에 도착 임박 푸시 발송) |
| **ETA 실시간 갱신** | SSE(Server-Sent Events) 기반 데이터 변경 감지 및 폴링 폴백을 결합한 반응형 갱신 구조 적용 |
| **픽업 장소 제안 및 변경** | 탑승자가 지도 핀으로 장소 변경을 제안하고, 차량에서 수락 시 내비게이션 경로를 자동 재탐색 |
| **지도 및 검색 인터랙션** | 카카오맵 SDK 연동 및 장소명·주소 검색, 지도 핀 선택 및 현재 GPS 위치 기반 장소 설정 지원 |

※ 현재 서비스는 공식 Pleos 에뮬레이터 환경에서 안정적인 동작 검증을 마쳤으며, 향후 실차 주행 환경에서의 필드 테스트 및 기기 연동 최적화를 지속적으로 진행할 예정입니다.
