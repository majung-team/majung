### 주요 설계 내용

**픽업 요청 및 연결**

- 카카오 로그인 및 마중 ID 기반 사람 검색
- QR 초대와 연결된 탑승자 직접 초대
- 탑승자의 장소 지정 픽업 요청
- 요청 수락 및 순차 픽업 처리
- 대기 중인 탑승자의 정보 접근 제한

**차량 및 실시간 정보**

- Pleos SDK 기반 경로·위치·ETA 활용
- 차량의 준비 상태 수신 및 음성 안내
- SSE 변경 신호와 API 재조회
- 연결 중단 및 정보 만료 처리
- 픽업 완료·취소 시 위치 공유 종료

상세 구현 방식과 데이터 검증 기준은 아키텍처 문서를 참고하면 된다.

## 문서 관리 기준

- 서비스 이용 흐름이 바뀌면 README와 Wiki를 함께 갱신
- 시스템 구조 변경 시 아키텍처와 다이어그램 갱신
- 기능 구현 시 관련 PR과 커밋을 개발 현황에 기록
- 운영 배포 및 검증 결과는 날짜별로 구분
- 미검증 기능을 완료 항목으로 표시하지 않음
- 개인정보, 인증 토큰 및 비공개 제출 서류는 공개 저장소에 포함하지 않음

현재 개발 단계와 실제 검증 범위는 [개발 현황](development-status.md) 및 [남은 작업](remaining-work.md)에서 확인할 수 있다.
