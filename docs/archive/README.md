# 분리 전 통합 버전 기록

이 저장소에서 차량 앱·서버·웹을 함께 개발했던 코드와 자료를 보존합니다.
최신 실행 방법은 [현재 개발 저장소](../../README.md#개발-저장소)를 따릅니다.

| 기록 | 내용 |
| --- | --- |

| [당시 작동 원리와 코드 구조](integrated-architecture.md) | 통합 폴더 구조와 주요 파일·API 흐름 |
| [차량 SDK 연동 기록](../vehicle-telemetry.md) | 목적지·위치·ETA, 해제·재연결 검증 |

`vehicle/`, `server/`, `web/`, `probe/`, `design/prototype/`도 같은 시점의 기록입니다.
새 기능은 분리한 저장소에서 진행하고 과거 기록을 최신 API·설정의 근거로 사용하지 않습니다.
이미지·영상은 기존 경로를 유지해 이전 링크로도 열 수 있게 합니다.
