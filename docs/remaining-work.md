2026년 10월 30일 기준. 추가 테스트는 보류하고 제출 자료 정리를 먼저 진행한다. 보류한 시험을 완료로 바꾸지는 않는다. 초기 성모·승준 분담과 실제 기여는 [PR 대조표](development-status.md)에 남겼다.

## 지금 할 일

1. 대표자가 수정한 접수양식을 기준으로 README·Wiki·노션·제출 안내의 설명을 맞춘다. 접수양식 원본의 문장과 구성은 유지한다.
2. [10월 29일 시연](pickup-demo.md)과 [0.2.14-preview APK](https://github.com/majung-team/majung-vehicle-app/releases/tag/v0.2.14-preview.20261029)를 제출 자료에 연결한다. 영상에 없는 기능은 구현 설명과 구분한다.
3. 비공개 저장소의 심사용 계정 접근, APK 파일명, 참가자 전원의 동의·서명·날짜와 CC를 제출 전에 확인한다. 연락처와 서명은 공개 문서에 넣지 않는다.

## 현재 확인 범위

- 공식 SDK·시험 서버·에뮬레이터에서 픽업과 장소 변경, 순차 처리, 종료·복구를 시험했다.
- 실제 아이폰 Chrome에서 공개 HTTPS, 로그인·탭 이동·검색·재접속을 확인했다. 입력 확대와 빈 목록의 페이지 버튼을 수정·배포했다([web #73](https://github.com/majung-team/majung-web/pull/73)).
- 현재 아이폰은 운전자와 같은 계정이다. 다른 탑승자의 요청부터 공유 종료까지 실기기 전체 흐름을 완료한 것으로 기록하지 않는다.
- 블루·그린 전환과 PostgreSQL 공유 세션은 운영에 적용했다. VM·DB 이중화는 아니다.

## 보류한 시험과 후속 개발

- 다른 계정의 전체 픽업 흐름, 여러 탑승자 순차 처리의 실제 휴대전화 시험
- 실제 GPS·권한 거절·LTE 전환·알림 배너, SDK 도착 이벤트·음성 청취·통화 우선순위·장시간 실행·실차 시험
- SDK 내비 취소 후 안내 유지 [차량 #56](https://github.com/majung-team/majung-vehicle-app/issues/56)
- 경유지 원본 좌표 0 응답 [차량 #13](https://github.com/majung-team/majung-vehicle-app/issues/13): 앱의 식별자 대조·경로·ETA·재연결 시험은 통과했고 제공 측 원본 응답은 공식 문의 후 답변 대기
- 10.2 익명 지표 집계, 정기 DB 복원 점검

VIN 연동은 현재 필수 범위가 아니다. 앱 등록 ID를 차대번호나 차량 소유권 인증으로 설명하지 않는다. 사용자 조사·설문·인터뷰는 이번 제출 범위에서 제외한다.
