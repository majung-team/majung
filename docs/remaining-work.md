# 남은 개발·검증

2026-10-28 기준. 현재 이후 작업은 승준이 혼자 이어간다.
초기 성모·승준 분담과 실제 기여는 [PR 대조표](development-status.md)에 남겼다.
열린 이슈 개수나 PR 작성자만으로 담당·완료 여부를 판단하지 않는다.

## 먼저 확인할 것

1. 서로 다른 카카오 계정으로 차량·실제 휴대전화 전체 흐름을 확인한다.
   QR·직접 초대·신규 요청 → 준비 변경 → 도착 → 탑승 완료 → 위치 접근 종료 순서다.
2. 두 번째·세 번째 탑승자의 요청을 대기에 두고 한 건씩 이어가는지 확인한다.
3. 실제 LTE·권한 거절·끊김·재접속, 휴대전화 알림 배너와 GPS를 확인한다.
4. SDK 도착 이벤트·음성 청취·통화 우선순위·장시간 실행을 별도로 시험한다.
   내비 취소 후 안내 유지 [차량 #56](https://github.com/majung-team/majung-vehicle-app/issues/56)은 미해결이다.
5. 최신 화면으로 시연을 다시 촬영하고 제출 버전을 고정한다.
