# 담당별 남은 작업

확인일: 2026-10-27. [노션 역할 분담](https://app.notion.com/p/10-4026da9ae26a80c6bb08c5550c5d02be), 네 저장소 main과 열린 PR을 대조했다. 원래 기능 담당을 기준으로 정리했으며, 실제 커밋 작성자를 근거로 담당을 바꾸지는 않았다. 구현 완료와 실기기 검증 완료는 구분한다.

## 성모 담당

참여·연결 끊기·QR·공유·지도·장소 제안·푸시의 주요 코드는 main에 있다. 서버·웹 배포도 운영 중이다. 남은 양을 열린 이슈 개수로 세지 않는다. 끝난 기능의 이슈가 아직 열려 있는 경우가 있다.

| 남은 일 | 확인할 것 |
| --- | --- |
| 휴대전화 기본 흐름 | 로그인, QR 공유, 초대 수락, 준비 변경, 종료까지 두 기기에서 확인 |
| LTE·끊김·재접속 | 연결 끊김 즉시 숨김, 마지막 정보·시간 표시, 복구 뒤 최신 정보만 표시 |
| 도착 알림 | 실제 휴대전화 배너, 허용·해제, iPhone 홈 화면 설치 조건, 중복 발송 방지 |
| 장소 제안 | 휴대전화 검색·핀 선택 → 차량 승인 → 새 장소 확정까지 실제 화면 확인 |
| 시연·제출 | 탑승자 화면 녹화·편집, 기획서의 문제·타깃·사업성, 동의서·메일·심사용 계정 초대 |

휴대전화에서 검증이 끝났다는 새 기록을 아직 확인하지 못한 항목은 남겨뒀다. 모든 작업을 다시 개발해야 한다는 뜻은 아니다.

## 승준 담당

경유지·해당 지점 ETA·백그라운드 전송·토큰 복구·주행 제한·음성 안내·자동 종료·보관 파기·장소 확정·차량 수신 확인의 주요 구현은 main에 있다. 차량 핵심 기능 개발은 대부분 끝난 상태지만 아래 항목은 남아 있다.

| 구분 | 남은 일 |
| --- | --- |
| 이번 개선 | 차량 내 사람 검색·연결 요청·받은 요청 승인/거절, 장소 확인 대기와 초기 표시 개선 |
| 실제 환경 확인 | SDK 도착 이벤트의 안정적 재현, 음성 실제 청취·통화 우선순위, 장시간 실행, 휴대전화와 전체 흐름 |
| 후속 서버 기능 | 10.2 익명 지표 집계 |
| 운영 정보 확정 뒤 | 10.4 차량 첫 사용 동의와 정식 처리방침. 현재 안내 문구만으로 완료 처리하지 않음 |
| 제출 준비 | 차량 화면 녹화, 최종 release APK·실행 안내, 기획서의 개발 계획·SDK 활용 |

10.2와 10.4는 이전에 후속으로 구분한 항목이다. 이번 사람 검색·로딩 개선에 섞어서 임의로 개발 범위를 늘리지 않는다. VIN 연동도 현재 필수 기능으로 추가하지 않는다.

## 함께 확인할 것

- 실제 휴대전화 2대 또는 서로 다른 계정으로 여러 탑승자 요청·대기 순서 확인
- 내비 장소 변경 중 초대·픽업 시작이 잘못 진행되지 않는지 확인
- 설문·인터뷰, 최신 흐름 시연 영상과 제출 자료 준비
- 기존 문서의 ‘관리자 일회용 최초 등록 코드’ 설명은 현재 QR 로그인 최초 연결 방식과 구분

현재 식별자는 마중 서버가 발급한 앱 등록 ID다. 실제 차량 VIN이나 소유권 인증과 혼동하지 않는다. SDK 에뮬레이터 시험은 실차 검증으로 표현하지 않는다.
