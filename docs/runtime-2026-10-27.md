[차량 0.2.0 시험 APK](https://github.com/majung-team/majung-vehicle-app/releases/tag/v0.2.0-preview.20261027)에서 설치 파일·SHA256SUMS·빌드 정보를 받는다. 비공개 저장소 접근 권한이 필요하다.

서버 SSE는 좌표를 계속 전송하는 별도 통로가 아니다. 변경 신호를 보내고 웹이 인증 API로 상태를 다시 읽는다. 서버는 DB를 약 1초마다 비교하며, 차량 SDK 조회는 약 5초 간격이다. 웹 스트림이 끊기면 3초 조회로 돌아간다. 서버 시험에 쓴 가상 픽업은 취소하고 시험 차량 권한은 철회했다.

## 반영한 화면

차량은 픽업·마중 요청·설정으로 나눴고 현재 준비 상태와 도착 시간을 먼저 보여준다. 웹은 픽업·사람 찾기·내 정보로 나눴다. 장소 제안은 차량에서 경로를 확인하고 확정한 뒤에 반영한다.

차량 화면은 공식 Pleos 에뮬레이터에서, 웹은 데스크톱 브라우저와 모바일 폭 미리보기에서 확인했다. 실제 휴대전화의 GPS·알림 배너·LTE 전환과 실차 주행은 이번 기록의 통과 범위에 포함하지 않는다.
