## 이번 확인

- 차량 아이콘을 웹과 같은 심볼로 바꾸고 SDK 진단 앱만 사용자 AVD에서 제거했다. 마중 앱·데이터는 삭제하지 않았다.
- 팝업 버튼이 부모 영역보다 위로 나가 잘리는 배치를 수정했다.
- 연결 상태 새로고침 중 기존 정보·버튼 위치·스크롤 유지와 중복 조회 방지를 시험했다.
- 웹의 차량 정보와 연결 해제 버튼을 분리하고 390px 화면의 가로 넘침을 확인했다.
- 웹 테스트 64건, 차량 단위 테스트·lint, 계정·복구·주행 요약 계측 11건을 실행했다.
  별도 실제 P→D→P 시험 1건은 조건을 충족하지 않아 건너뛰었다.

이는 공개 서버 health와 웹 배포 확인, 가상 계정을 사용한 브라우저·독립 에뮬레이터 시험이다.
실제 사용자의 차량 연결을 해제하지 않았고, 휴대전화 전체 시연·실차 시험을 수행한 결과는 아니다.
기존 10월 26~27일 보고서는 당시 결과로 보관한다.
