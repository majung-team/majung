## 형식 요건

- 접수 이메일: appdevchallenge@hyundai-partners.com. 대표자가 팀원 전원을 참조(CC)에 넣는다.
- 수정 제출은 마감 전에 처음 보낸 주소로 다시 보낸다. 제목 앞에 `[수정제출]`을 붙이고 모든 자료와 서명한 동의서를 다시 첨부한다. 마감 전 마지막 제출본이 최종본이다.
- APK는 저장소의 `apk/` 폴더에 실행 가능한 release 버전으로 올린다. 용량이 크면 GitHub Releases에 올리고 그 페이지 주소를 제출한다.
- 비공개 저장소는 심사용 GitHub 계정을 Collaborator로 초대한다. 개인 계정 저장소의 Collaborator는 쓰기 권한도 가진다. 조직 저장소는 필요한 읽기 권한을 확인하고, 마감 전에 심사용 계정으로 접근되는지 확인한다.
- 제출 저장소의 README에는 앱 이름과 한 줄 소개, 실행 방법, 테스트 환경과 필요한 설정, APK 위치 또는 Release 링크가 있어야 한다.

## 기존 시연과 추가 촬영

10월 29일 기본 흐름 영상은 촬영을 마쳤다. 아래는 추가 촬영을 선택할 때 사용할 순서이며 제출 전 필수 시험 목록은 아니다: 차량에서 픽업 생성 → 운전자 휴대전화로 QR 열기 → 탑승자에게 링크 공유 → 탑승자 참여(이름·승인 없음) → 지도에서 차량 위치와 남은 시간 → 준비 완료가 차량에 표시 → 도착 → 탑승 확인과 공유 종료. 도착 임박 알림과 장소 제안은 시연할 수 있게 되면 넣는다.

- 영상에 쓴 저장소별 커밋을 기록한다.
- 시험용 계정과 장소만 쓴다. 초대 토큰, 실제 개인 위치, 서버 주소 외의 운영 정보가 화면에 나오지 않게 한다.
- 실제 SDK 데이터와 시뮬레이션 데이터를 구분해 자막이나 설명에 적는다.

## 개인정보와 공개 범위

- 동의서는 서명이 필요한 개인정보다. 저장소에 올리지 않고 메일로만 보낸다.
- 공식 안내상 일반 참가자 정보는 후속 일정이 끝나는 2027-02-28까지 보관 후 파기되며, 수상자는 결과 발표일부터 2년 보관한다.
