# 마중 사용 안내

마중은 운전자와 탑승자가 만날 장소, 도착 시간, 준비 상태를 함께 확인하는 서비스다.
차량에는 마중 앱을 설치하고, 휴대전화에서는 웹을 연다. 탑승자 휴대전화에 별도 앱을 설치할 필요는 없다.

- 웹 접속: **https://majung.cloud**
- 내 픽업과 사람 찾기: **https://majung.cloud/account**
- 차량 앱: [차량 저장소의 Releases](https://github.com/majung-team/majung-vehicle-app/releases)에서 설치 파일과 버전을 확인한다. 현재는 공식 Pleos 에뮬레이터에서 시험한다.

처음이라면 아래 순서로 읽으면 된다.

1. [차량 앱 설치와 처음 설정](차량-앱-설치.md)
2. [휴대전화에서 마중 요청하기](웹에서-시작하기.md)
3. [두 사람이 함께 테스트하기](함께-테스트하기.md)

웹 주소만 열어도 사용할 수 있지만, 차량 앱이 실행 중이고 내비에서 경로가 확인돼야 위치와 도착 시간을 볼 수 있다. 아직 실차에서 검증한 서비스는 아니다.

코드 구조와 운영 확인은 [아키텍처](../architecture.md), [배포 확인](../runtime-2026-10-28.md), [개발 규칙](../../CONTRIBUTING.md)을 참고한다.

현재 개발은 승준이 혼자 이어간다. 초기 기여와 실제 반영은 [개발 현황과 PR 근거](../development-status.md)를 본다.
