# 문서 위치 안내

[사용 안내 첫 페이지](Home.md)에서 시작한다.

현재 `majung-team`은 GitHub Free이고 `majung`은 비공개 저장소다. GitHub Wiki 활성화를 API로 시도했으나 `has_wiki: false`가 유지됐고 Wiki Git 저장소에도 접근할 수 없었다. 비공개 조직 저장소의 Wiki는 유료 요금제에서 제공된다([GitHub 안내](https://docs.github.com/en/communities/documenting-your-project-with-wikis/about-wikis)).

요금제나 저장소 공개 범위를 바꾸지 않고 같은 내용을 이 폴더에서 읽을 수 있도록 나눴다. Wiki를 사용할 수 있게 되면 이 문서들을 그대로 옮길 수 있다.
