# 마중 개발 문서

## 어떤 서비스인가

누군가를 데리러 갈 때 운전자는 ‘준비됐어?’, 기다리는 사람은 ‘몇 분 남았어?’를 반복해서 묻게 된다.
마중은 내비게이션의 픽업 장소·도착 예정 시간과 탑승자의 준비 상태를 같은 약속으로 묶어 이 연락을 줄이려는 서비스다.

운전자는 차량 앱, 탑승자는 초대 링크로 연 웹을 사용하는 안이다. 탑승자용 앱은 이후 확장 방향으로 두고,
첫 버전에서는 설치 없이 참여하는 흐름부터 검증한다. 서버 API는 웹에서 사용하고 있으며, 이후 탑승자 앱도 같은 API를 사용한다.

## 지금 구현된 범위

| 구성 | 상태 | 실행 근거 |
| --- | --- | --- |
| SDK 확인용 Android 앱 | 구현·에뮬레이터 시험 완료 | NaviHelper 연결, 위치 조회, 예제 경로 ETA, Activity stopped 상태 수동 조회 |
| 차량·휴대전화 화면 초안 | 구현·브라우저 조작 확인 | 초대, 참여 확인, 준비 상태, 장소 변경, 도착, 공유 종료 |
| 상태 모델 | 구현·8개 테스트 통과 | 승인 전 비공개, 경로 실패, 종료·만료, 재접속 처리 |
| 탑승자 웹 | SDK·로컬 API 연동 확인 | 참여·승인·SDK 위치·ETA 표시·준비 상태·공유 종료. 지도·외부 배포는 후속 작업 |
| 픽업 서버·권한 | 로컬 API 구현·HTTP 시험 완료 | 생성·참여 승인·준비 상태·차량 정보·종료, 픽업별 토큰. 계정 로그인은 미구현 |
| 차량 위치·ETA 공유 | 에뮬레이터·서버·웹 연결 확인 | 승인 후 전송, SDK 해제 시 무효화. 실차·실제 휴대전화는 미검증 |
| 차량 도착·탑승 완료 | 차량 UI·로컬 API 시험 완료 | 운전자 확인 창, 도착 후 공유 유지, 완료 후 접근 차단·새 픽업 준비 |
| 실제 지도 | 미구현 | 현재 웹은 좌표·ETA를 표시하며 지도는 없음 |
| 탑승자용 네이티브 앱 | 향후 확장 | 웹·앱 공통 API 사용 예정 |

## 다음 구현

픽업 기본 API를 구현했고 승인 전 조회 차단, 다른 약속 조회 차단, 초대 만료·철회, 종료 후 접근 차단을 확인했다.
차량 생성·승인·SDK 전송·준비 상태·도착·탑승 완료까지 로컬 서버와 연결했다. 도착 뒤 공유 유지와 완료 후 접근 차단을 공식 에뮬레이터에서 확인했다. 이 흐름의 시연 편집본도 기록했다. 다음은 실제 휴대전화와의 통신·외부 HTTPS 연결이다. 기존 화면 초안의 예시 데이터는 그대로다.

개발 기본값은 초대 15분·픽업 2시간이다. 실서비스의 수명 정책, 장소 변경, 지도 공급자와 배포 방식은 추가 검토가 필요하다.
현재 화면을 실제 Pleos 주행 중 허용 UI로 판단하지 않는다. 실차·장시간 백그라운드·자동 위치 갱신 주기 시험도 남아 있다.

## 실행 근거 관리

`docs/media/`에는 예시 화면과 공식 에뮬레이터의 SDK 연동 캡처를 구분해 넣는다.
`sdk-web-flow.gif`는 실제 연동 캡처 2장을 반복하며 연속 녹화가 아니다. 실차 주행 자료로 소개하지 않는다.
기기의 원본 위치 로그, 로컬 환경 경로, 개인 계정·인증 화면은 `evidence/private/`에 두고 올리지 않는다.
공식 SDK·에뮬레이터 바이너리는 저장소에 포함하지 않는다.
