# 마중 개발 문서

## 어떤 서비스인가

누군가를 데리러 갈 때 운전자는 ‘준비됐어?’, 기다리는 사람은 ‘몇 분 남았어?’를 반복해서 묻게 된다.
마중은 내비게이션의 픽업 장소·도착 예정 시간과 탑승자의 준비 상태를 같은 약속으로 묶어 이 연락을 줄이려는 서비스다.

운전자는 차량 앱, 탑승자는 초대 링크로 연 웹을 사용하는 안이다. 탑승자용 앱은 이후 확장 방향으로 두고,
첫 버전에서는 설치 없이 참여하는 흐름부터 검증한다. 서버 API는 향후 웹과 앱이 함께 사용할 수 있도록 설계할 예정이다.

## 다음 구현

‘픽업 한 건 생성 → 탑승자 참여 확인 → 준비 상태 전달 → 공유 종료’를 실제 서버로 연결한다.
위치를 외부로 전송하기 전에 승인 전 조회 차단, 다른 약속 조회 차단, 초대 만료·철회, 종료 후 접근 차단부터 확인한다.

장소 변경을 첫 버전에 넣을지, 연결 번호와 초대 토큰의 수명, 지도 공급자와 통신 방식은 아직 확정하지 않았다.
현재 화면을 실제 Pleos 주행 중 허용 UI로 판단하지 않는다. 실차·장시간 백그라운드·자동 위치 갱신 주기 시험도 남아 있다.

## 실행 근거 관리

`docs/media/`에는 예시 데이터로 실행한 브라우저 캡처만 넣는다.
기기의 원본 위치 로그, 로컬 환경 경로, 개인 계정·인증 화면은 `evidence/private/`에 두고 올리지 않는다.
공식 SDK·에뮬레이터 바이너리는 저장소에 포함하지 않는다.
