
# 차량 앱 설치와 처음 설정

마중 차량 앱은 **Pleos Connect 공식 에뮬레이터**에서 실행하는 Android Automotive OS(AAOS) 애플리케이션이다.

일반 안드로이드 휴대전화에 설치하는 앱이 아니며, 현재 실제 차량 환경에서의 검증은 완료되지 않았다.

이 문서에서는 차량 앱 설치부터 최초 계정 연결, 픽업 시작까지의 과정을 안내한다.

---

## 1. 차량 앱 설치

### APK 다운로드

[차량 앱 Releases](https://github.com/majung-team/majung-vehicle-app/releases)에서 설치 파일을 다운로드한다.

현재 안내 기준 버전:

**[v0.2.16-preview (2026.10.31)](https://github.com/majung-team/majung-vehicle-app/releases/tag/v0.2.16-preview.20261031)**

APK 파일명: `Majung_Majung_release.apk`

새 버전이 등록됐다면 Releases 페이지에서 최신 버전을 확인하면 된다.

### 에뮬레이터 설치

Android Studio에서 Pleos 공식 에뮬레이터를 실행한 뒤 APK를 설치한다.

먼저 터미널에서 연결된 기기를 확인한다.

```sh
adb devices
```

예상 출력:

```text
List of devices attached
emulator-5554    device
```

기기가 정상적으로 연결됐다면 APK를 설치한다.

```sh
adb -s emulator-5554 install -r ~/Downloads/Majung_Majung_release.apk
```

- `emulator-5554`: `adb devices`에 표시된 기기 이름
- `~/Downloads/Majung_Majung_release.apk`: 다운로드한 APK의 실제 경로
- `-r`: 기존 앱 데이터를 유지하면서 업데이트 설치 시도

설치가 완료되면 에뮬레이터의 앱 목록에서 **마중**을 실행한다.

### 기존 앱과 서명이 다른 경우

개발용 APK와 Release APK의 서명이 다르면 기존 앱 위에 설치할 수 없다.

이 경우 다음 사항을 먼저 확인해야 한다.

1. 진행 중인 픽업 종료
2. 기존 차량 연결 및 계정 정보 확인
3. 필요한 경우 차량 재등록 준비
4. 기존 앱 제거 후 새 APK 설치

앱을 삭제하면 차량에 로컬로 저장된 등록 및 접근 정보도 삭제될 수 있다.

**서명 충돌이 발생했다고 무조건 앱을 삭제하지 말고, 진행 중인 픽업과 차량 연결 상태를 먼저 확인한다.**

---

## 2. 최초 계정 연결

처음 실행한 차량 앱은 운전자 계정과 연결해야 한다.

관리자 코드 없이 차량에서 생성한 QR코드와 운전자 본인의 휴대전화를 사용한다.

### 연결 순서

1. 에뮬레이터 앱 목록에서 **마중** 실행
2. 정차 상태에서 위치 공유 안내 확인 및 동의
3. **휴대전화로 시작하기 · QR 만들기** 선택
4. 운전자 휴대전화로 QR코드 열기
5. 카카오 로그인 및 닉네임 설정
6. 휴대전화에서 **이 계정으로 차량 연결 요청** 선택
7. 차량에서 **요청한 계정 확인하고 연결** 선택
8. 닉네임과 마중 ID가 본인 계정인지 확인
9. **이 계정으로 연결** 선택

연결이 완료되면 차량 등록과 운전자 계정 연결이 함께 처리된다.

### QR코드 유효 시간

QR코드는 생성 후 **5분간 유효**하다.

다음 상황에서는 차량에서 새 QR코드를 생성하면 된다.

- QR코드 유효 시간이 지난 경우
- 다른 계정으로 연결을 요청한 경우
- 연결 요청을 다시 진행해야 하는 경우

이미 등록된 차량은 기존 연결 권한을 유지한다.

탑승자는 차량 등록 과정이 필요하지 않으며, 모바일 웹을 이용하면 된다.

## 3. 픽업 시작하기

계정 연결이 완료되면 차량 내비게이션에서 경로를 설정하고 픽업을 시작할 수 있다.

### 픽업 장소 설정

1. 차량 내비게이션에서 경로 안내 시작
2. 마중 앱의 **픽업** 화면 열기
3. 내비게이션 경로 및 픽업 장소 확인
4. 최종 목적지 또는 픽업 경유지 선택
5. 장소와 경로 검증 후 픽업 진행

기존 최종 목적지를 유지하면서 필요한 픽업 장소를 경유지로 추가할 수 있다.

경로가 확인되지 않으면 픽업 생성이 제한될 수 있다.

### 기존 경유지에서 만나기

**경유지에서 만나기**는 내비에 이미 있는 경유지를 선택하는 기능이다. **다른 장소에서 만나기**는 최근 장소를 새 경유지로 추가한다.

기존 경유지의 위치를 확인하지 못하면 **위치 다시 선택**에서 정확한 장소를 고른다. 같은 이름이면 주소도 확인한다. 위치를 모르는 경유지가 두 곳이면 모두 고른 뒤 경유지 순서와 최종 목적지를 확인한다.

**경로 확인하고 변경**을 누르기 전에는 경로를 바꾸지 않는다. 선택 중 기존 경로가 달라지면 다시 확인한다. 최근 장소 목록에도 없으면 내비에서 장소를 검색한 뒤 돌아온다.

좌표 확인 방식과 시험 범위는 [경유지 좌표 대응](https://github.com/majung-team/majung-vehicle-app/blob/main/docs/waypoint-coordinates.md)에 정리했다. SDK 원본의 `(0,0)` 반환이 수정된 것은 아니다.

### 처음 만나는 탑승자 초대

1. 마중 앱에서 픽업 장소 확인
2. QR 기반 초대 생성
3. 차량 QR코드를 운전자 휴대전화로 열기
4. 휴대전화 공유 화면에서 초대 링크 전달
5. 탑승자가 웹에서 초대 수락
6. 해당 픽업 시작 후 위치 및 예상 도착 시간 공유

### 이미 연결된 탑승자 초대

1. **픽업 → 연결된 사람 선택** 이동
2. 초대할 탑승자 선택
3. 픽업 초대 전송
4. 탑승자가 웹의 **내 픽업**에서 초대 수락
5. 해당 픽업 시작 후 상태 확인

매번 QR코드를 생성하지 않아도 기존 연결을 이용해 픽업에 초대할 수 있다.

## 4. 탑승자의 픽업 요청 확인

탑승자는 모바일 웹에서 운전자를 찾아 먼저 픽업을 요청할 수도 있다.

차량에서는 **받은 요청** 메뉴에서 요청 내용을 확인한다.

1. **받은 요청** 이동
2. 탑승자가 요청한 픽업 장소 확인
3. 내비게이션 경로 검증
4. 요청 수락
5. 픽업 진행

여러 요청은 대기열에서 관리하며, 픽업은 한 번에 한 건씩 진행한다.

현재 픽업이 종료되면 다음 요청의 장소와 경로를 확인해 이어갈 수 있다.

---

## 5. 주행 중 이용 제한

마중은 차량 시스템의 주행 제한 정책을 따른다.

주행 제한이 적용되는 상황에서는 상세 조작 화면 대신 필요한 정보만 간략하게 표시한다.

다음 작업은 안전하게 정차한 상태에서 진행한다.

- 픽업 장소 변경
- 새로운 픽업 요청 수락
- 사람 검색 및 연결 관리
- 계정 연결과 초기 설정

설정의 **사람 찾기 · 연결 관리**에서는 닉네임 또는 마중 ID로 사람을 검색하고 연결 상태를 관리할 수 있다.

## 6. 설치 및 연결 문제 해결

### `No connected devices`가 표시되는 경우

ADB에서 실행 중인 에뮬레이터를 찾지 못한 상태다.

다음 명령으로 확인한다.

```sh
adb devices
```

에뮬레이터가 실행되어 있는지 확인하고, 기기 목록에 나타난 뒤 설치를 다시 시도한다.

### `OFFLINE`이 표시되는 경우

ADB가 에뮬레이터를 인식했지만 정상적으로 통신하지 못하는 상태다.

이미 실행한 에뮬레이터를 중복 실행하지 않았는지 확인한다.

기기 상태가 `device`로 변경된 후 설치를 진행한다.

### APK가 설치되지 않는 경우

다음 사항을 확인한다.

- APK 파일 경로가 올바른지
- 에뮬레이터가 실행 중인지
- ADB에서 기기가 `device` 상태인지
- 기존 앱과 APK 서명이 충돌하는지
- 설치 대상이 Pleos 공식 에뮬레이터인지

기존 앱과 서명이 다르다면 앞의 **기존 앱과 서명이 다른 경우** 항목을 참고한다.

### QR코드 연결이 되지 않는 경우

다음 내용을 확인한다.

- QR코드 생성 후 5분이 지나지 않았는지
- 운전자 본인의 카카오 계정으로 로그인했는지
- 휴대전화에서 차량 연결 요청을 완료했는지
- 차량에서 요청 계정을 확인하고 최종 승인했는지

QR코드가 만료됐다면 차량에서 새로 생성한다.

## 7. 참고 사항

- **마중**: 실제 픽업 기능을 사용하는 차량 애플리케이션
- **마중 SDK 확인**: 개발 과정에서 SDK 동작을 확인하는 진단용 애플리케이션

일반적인 픽업 테스트에는 **마중** 앱만 사용하면 된다.

실제 차량 환경에서의 동작과 앱마켓 배포 가능 여부는 추가 검증이 필요하다.
