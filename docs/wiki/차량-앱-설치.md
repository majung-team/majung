# 차량 앱 설치와 처음 설정

## 어디에 설치하나요?

차량 앱은 **공식 Pleos 에뮬레이터**에 설치한다. 일반 휴대전화용 앱이 아니다. Android Studio는 설치와 개발에 쓰고, 실행된 에뮬레이터의 앱 목록에서 마중을 열 수 있다.

[차량 앱 시험 버전 목록](https://github.com/majung-team/majung-vehicle-app/releases)에서 APK를 받는다. 비공개 저장소라 팀 계정으로 로그인해야 한다.

[현재 시험 APK는 0.2.14-preview](https://github.com/majung-team/majung-vehicle-app/releases/tag/v0.2.14-preview.20261029)다. 관리자 코드 없이 휴대전화 QR로 처음 연결한다. 기존 개발 앱과 release APK의 서명이 다르면 덮어쓸 수 없으므로 아래 서명 안내를 먼저 확인한다.

에뮬레이터가 실행된 상태에서 설치한다.

```sh
adb devices
adb -s emulator-5554 install -r /받은/경로/vehicle-release.apk
```

`emulator-5554`는 `adb devices`에 나온 기기 이름으로 바꾼다. APK 파일 경로도 실제 받은 위치로 바꾼다.

기존 개발용 앱과 새 release 앱의 서명이 다르면 덮어쓸 수 없다. 기존 앱을 지우면 차량에 저장된 등록·픽업 접근 정보도 지워진다. 진행 중 픽업을 먼저 끝내고 필요한 차량 재등록을 준비한 뒤 교체한다. 서명이 다르다는 오류를 무시해서 설치하지 않는다.

## 처음 한 번 할 일

1. 앱 목록에서 **마중**을 연다. 주차 상태에서 위치 공유 안내를 확인하고 동의한 뒤 시작한다.
2. **휴대전화로 시작하기 · QR 만들기**를 누른다. 픽업 탭에서도 시작할 수 있다.
3. 운전자 본인 휴대전화로 QR을 열어 카카오 로그인과 닉네임 설정을 마친다.
4. 휴대전화에서 **이 계정으로 차량 연결 요청**을 누른다.
5. 차량의 **요청한 계정 확인하고 연결**을 누르고 닉네임·마중 ID가 본인인지 확인한다.
6. **이 계정으로 연결**을 누르면 등록과 운전자 연결이 함께 끝난다. 이후 다시 하지 않는다.

QR은 5분 동안만 유효하다. 잘못된 계정이 요청했거나 만료됐으면 차량에서 새 QR을 만든다. 관리자에게 코드를 받을 필요는 없다. 이미 등록된 차량은 기존 권한을 유지한다.

탑승자는 차량 등록이나 이 계정 연결을 하지 않는다.

## 픽업 시작

내비게이션에서 경로를 안내한 뒤 **픽업**에서 장소를 확인한다. 최종 목적지에서 태우거나, 최근 장소를 픽업 경유지로 추가할 수 있다. 앱에서 장소와 경로가 확인돼야 픽업을 만들 수 있다.

초대하는 방법은 두 가지다.

- **처음 만나는 사람**: 픽업을 만들고 QR을 운전자 휴대전화로 연다. 열린 공유 화면에서 탑승자에게 초대 링크를 보낸다.
- **이미 연결된 사람**: **픽업 → 연결된 사람 선택**에서 탑승자를 골라 초대를 보낸다. 탑승자는 웹의 내 픽업에서 수락한다.

받은 마중 요청은 **받은 요청**에서 확인한다. 여러 요청을 받아둘 수 있지만 픽업은 한 번에 한 건씩 진행한다.

주행 중에는 조작 화면 대신 요약이 표시된다. 장소 변경이나 요청 수락 등은 안전하게 정차한 뒤 한다.

설정의 **사람 찾기 · 연결 관리**에서는 차량에서도 닉네임·마중 ID로 사람을 찾을 수 있다.
‘마중 SDK 확인’은 진단용 앱이다. 일반 테스트는 ‘마중’만 열면 된다.

`No connected devices` 또는 `OFFLINE`이면 앱 빌드 오류가 아니라 기기 연결 상태다.
이미 실행된 에뮬레이터를 또 켜지 말고 `adb devices`에서 `device` 상태가 될 때 설치한다.
