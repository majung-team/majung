# 차량 앱 설치와 처음 설정

## 어디에 설치하나요?

차량 앱은 **공식 Pleos 에뮬레이터**에 설치한다. 일반 휴대전화용 앱이 아니다. Android Studio는 설치와 개발에 쓰고, 실행된 에뮬레이터의 앱 목록에서 마중을 열 수 있다.

[차량 앱 0.2.0 시험 버전](https://github.com/majung-team/majung-vehicle-app/releases/tag/v0.2.0-preview.20261027)에서 APK를 받는다. 비공개 저장소라 팀 계정으로 로그인해야 한다.

에뮬레이터가 실행된 상태에서 설치한다.

```sh
adb devices
adb -s emulator-5554 install -r /받은/경로/majung-release.apk
```

`emulator-5554`는 `adb devices`에 나온 기기 이름으로 바꾼다. APK 파일 경로도 실제 받은 위치로 바꾼다.

기존 개발용 앱과 새 release 앱의 서명이 다르면 덮어쓸 수 없다. 기존 앱을 지우면 차량에 저장된 등록·픽업 접근 정보도 지워진다. 진행 중 픽업을 먼저 끝내고 필요한 차량 재등록을 준비한 뒤 교체한다. 서명이 다르다는 오류를 무시해서 설치하지 않는다.

## 처음 한 번 할 일

1. 앱 목록에서 **마중**을 연다.
2. **설정**에서 **차량 최초 등록**을 누른다.
3. 승준에게 받은 일회용 등록 코드를 입력한다. 이 코드는 문서나 채팅방 공지에 올리지 않는다.
4. **운전자 계정 연결 QR 만들기**를 누른다.
5. 운전자 휴대전화로 QR을 열고 카카오 로그인 후 차량 연결을 요청한다.
6. 차량에서 표시된 닉네임과 마중 ID가 본인인지 확인하고 연결한다.

탑승자는 차량 등록이나 이 계정 연결을 하지 않는다.

## 픽업 시작

내비게이션에서 경로를 안내한 뒤 **픽업**에서 장소를 확인한다. 최종 목적지에서 태우거나, 최근 장소를 픽업 경유지로 추가할 수 있다. 앱에서 장소와 경로가 확인돼야 픽업을 만들 수 있다.

초대하는 방법은 두 가지다.

- **처음 만나는 사람**: 픽업을 만들고 QR을 운전자 휴대전화로 연다. 열린 공유 화면에서 탑승자에게 초대 링크를 보낸다.
- **이미 연결된 사람**: **마중 요청**에서 연결된 탑승자를 골라 초대를 보낸다. 탑승자는 웹의 내 픽업에서 수락한다.

받은 마중 요청은 **마중 요청**에서 확인한다. 여러 요청을 받아둘 수 있지만 픽업은 한 번에 한 건씩 진행한다.

주행 중에는 조작 화면 대신 요약이 표시된다. 장소 변경이나 요청 수락 등은 안전하게 정차한 뒤 한다.
